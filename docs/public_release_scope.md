# Public Release Scope

This public release is designed for technical evaluation and portfolio review.

## Included

- generic event-driven campaign state machine;
- generic one-permission Candidate B example;
- paired A/B divergence evaluator;
- next-open causal execution simulator;
- deterministic paper-shadow engine;
- immutable run manifests;
- negative research evidence and methodology;
- synthetic examples.

## Not included

- original personal trading notes;
- private TradingView exports/screenshots;
- proprietary indicator formulas or exact thresholds;
- exact internal timeframe labels;
- detailed production sizing recipes;
- API keys, account identifiers, or broker routes.

The private research repository remains the source of truth for proprietary signal generation.
